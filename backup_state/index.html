Quick Setup

Cài Đặt Bộ Mod Khởi Động

Để tham gia máy chủ OlongBell, bạn cần cài đặt đúng bộ Mod tương thích. Nhằm tối giản hóa các bước cài đặt thủ công phức tạp, chúng tôi cung cấp trình cài đặt tự động.

  • 1 Sao chép câu lệnh PowerShell bên cạnh.
  • 2 Nhấn phím Windows, gõ PowerShell và nhấn Enter.
  • 3 Chuột phải (hoặc nhấn Ctrl + V) để dán câu lệnh và nhấn Enter.
Trình cài đặt sẽ tự động tải các file Mod cần thiết và đưa trực tiếp vào thư mục .minecraft/mods của bạn.
olongbell-installer.ps1
